# Lumea : widgets

Widgets OBS de **Lumea**, le logiciel Windows gratuit qui affiche en direct les dons d'une campagne Streamlabs Charity.

Ce dépôt public contient :

- `widgets/` : les widgets HTML, CSS et JS (total de l'équipe, total par streamer, paliers, badge de don, roulette) ;
- `themes/` : les thèmes et réglages de base (couleurs, polices, textes) ;
- les installateurs de Lumea, dans les [releases](../../releases).

Chaque widget ne parle qu'au Lumea installé sur son propre PC, à l'adresse `127.0.0.1`. Il ne peut ni lire ni modifier les données de quelqu'un d'autre.

**État : en construction.** Les premiers widgets arrivent avec le lot 2 du projet. Aucune version publique n'est encore disponible.
